# 唐宋元明清 · 五朝历史图谱（单文件版）

一个**零依赖、单 HTML 文件**的纯前端历史数据可视化作品：将唐、宋、元、明、清五朝的本纪、人物、事件、引文数据全部内联，双击即可运行，也可直接部署为静态网站。

## 在线体验

https://yakiooo.github.io/tang-song-yuan-ming-qing-standalone/

（部署后替换为实际 Pages 地址）

## 功能

- **五朝本纪**：二十帝本纪按分行卡片呈现，含各帝本纪篇幅统计、年号对照
- **人物谱系**：60 位核心人物按「书中着墨字数」排行，人物页含人生轨迹、关键事件、书中引文（原文 + 校勘另说）
- **世代顺位图**：同代人物关系图谱，可下钻单个人物再返回
- **专题与总目**：按专题/类别分组的本纪导航
- **关键词检索**：人物关键词、书中提及定位

## 技术特点

- 单文件构建：全部数据与样式内联（约 10MB），无任何外部请求
- 兼容 `file://` 双击打开与 HTTP 部署两种运行方式
- 原生 JS + CSS，无框架、无构建依赖、无第三方 CDN
- hash 路由（`#tang` / `#song` …）支持直达指定朝代

## 本地运行

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 数据说明

内容整理自公开史料，人物页按「出身—起家—关键转折—事业高峰—结局与身后」五拍结构组织；引文标注书名与章节，异文另出校勘。
